# Role playbook templates

These short, optional copyable playbooks apply the canonical
[issue-first intake policy](../../docs/governance/task-intake.md) and stage rules
to [Manager](manager.md), [Developer](developer.md),
[Code Reviewer](code-reviewer.md) and [Verifier](verifier.md).
[Agent bootstrap](../../prompts/agent-bootstrap.md) is the shared base intake.

They do not appoint roles, install a team or replace existing profiles. Merge
only owner-approved guidance in the target project; keep relative policy links
valid after copying. Local installed-profile updates are a separate coordinated
step. The [root contract](../../AGENTS.md) and canonical governance apply to all.
